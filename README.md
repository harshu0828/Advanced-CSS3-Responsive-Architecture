 # Advanced CSS3 & Responsive Architecture

A modern, responsive personal portfolio website built using **HTML5, CSS3, and Vanilla JavaScript**. The project demonstrates advanced CSS layouts, responsive design, dark/light theme switching, animations, accessibility features, and interactive JavaScript functionality.

## 🌐 Project Overview

This portfolio website is designed to showcase my **education, technical skills, projects, experience, certifications, and contact information** in a clean and responsive interface.

The project focuses on applying modern frontend development concepts, especially **Advanced CSS3 and Responsive Architecture**.

## ✨ Features

* 📱 Fully responsive design for desktop, tablet, and mobile
* 🌓 Light/Dark theme switching
* 💾 Theme preference stored using `localStorage`
* 🧭 Responsive navigation with mobile hamburger menu
* 🎨 Modern UI using CSS variables
* 📐 CSS Grid and Flexbox layouts
* ✨ Scroll reveal animations
* 🔗 Active navigation link based on scroll position
* ⬆️ Back-to-top button
* ♿ Accessibility-focused design
* ⌨️ Keyboard-friendly navigation
* 🎞️ Smooth animations and transitions
* 📱 Multiple responsive breakpoints
* 📝 Client-side contact form validation
* ⚡ Reduced-motion support for accessibility

* Tablets

## ▶️ How to Run

### Option 1: Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### Option 2: Using VS Code

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
